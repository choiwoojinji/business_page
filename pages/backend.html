BACKEND

  • 01

    프로그래밍 언어 기초

    Python 또는 Node.js 문법을 익히고 기본 로직을 짜는 힘을 기릅니다.

    • 변수, 함수, 자료구조 등 언어 공통 기본기
    • Python 또는 Node.js 문법 실습
    • 알고리즘적 사고와 문제 해결 연습
  • 02

    서버와 HTTP

    요청과 응답이 오가는 원리를 이해하고 서버의 역할을 파악합니다.

    • 클라이언트-서버 구조와 요청/응답 흐름
    • HTTP 메서드(GET, POST 등)와 상태 코드
    • 서버를 직접 띄워보고 요청 받아보기
  • 03

    데이터베이스 기초

    SQL로 데이터를 저장, 조회, 수정하는 방법을 배웁니다.

    • 관계형 데이터베이스 개념과 테이블 설계
    • SQL로 CRUD(생성/조회/수정/삭제) 다루기
    • 인덱스와 기본적인 쿼리 최적화
  • 04

    API 설계

    REST API를 설계하고 프론트엔드와 데이터를 주고받습니다.

    • REST 원칙과 엔드포인트 설계
    • 요청/응답 데이터 형식(JSON) 다루기
    • 프론트엔드와 데이터 주고받는 연동 실습
  • 05

    인증과 보안

    로그인, 토큰 인증 등 서비스 운영에 필요한 기본 보안 개념을 익힙니다.

    • 로그인/회원가입 흐름과 비밀번호 암호화
    • 세션과 토큰(JWT) 기반 인증 이해
    • 기본적인 보안 취약점과 대응법
  • 06

    배포와 운영

    만든 서버를 실제로 올리고 안정적으로 운영하는 방법을 배웁니다.

    • 서버를 클라우드에 올리는 기본 절차
    • 환경변수와 설정 관리
    • 로그 확인과 간단한 장애 대응
